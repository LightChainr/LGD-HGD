# 25F 具体执行方案、数据申请与分析说明

版本：v1.1（资源闭合、E1可识别性与反污染修订）  
日期：2026-08-26  
用途：病理科、内镜中心、分子平台、数据平台主管、生信与统计团队共同讨论稿  
项目简称：25F / HGD Boundary Flagship

## 一、项目定位

### 1. 核心研究问题

在同一患者、同一病理等级（形态学 LGD）并控制腺体克隆关系后，HGD 边界周围的 LGD 腺体是否存在随真实组织距离变化的上皮—间质—免疫状态；该变化主要由局部边界生态、克隆扩张，还是整枚病灶的固有状态解释？

### 2. 旗舰创新点

本研究不做普通的 HGD 与 LGD 平均表达比较，而是同时控制四个容易混杂的因素：

1. 同一宿主；
2. 同一形态学等级；
3. 到真实 HGD/LGD 边界的连续组织内距离；
4. 腺体与 HGD 区的克隆关系。

公共数据只能用于冻结候选机制轴、确定细胞来源和建立克隆判定规则，不能代替本院的真实边界、腺体和蜡块数据。

### 3. 主要研究主张的边界

- 横断面材料不证明 LGD 在时间上进展为 HGD。
- 主要结论使用“空间关联”“边界生态关联”或“克隆条件化梯度”，不使用 `drives`、`induces`、`spreads` 等因果措辞。
- 患者是唯一独立统计单位；区域、腺体、ROI 和细胞均为患者内嵌套观测。
- 单个 APC/KRAS 等常见热点或宽臂 CNA 相似不能单独定义同一克隆。

## 二、研究对象与空间结构

### 1. 候选病例池

截至 2026-07-31 的工作区记录：

- 病理关键词候选：215 份报告、203 名患者；
- 主 HGD 候选：123 份报告、121 名患者；
- A 层候选约 112 份报告、110 名患者；
- 其中约 106 名患者在病理前 30 天内存在候选内镜记录。

这些数字仅是筛选分母，不代表有可用蜡块、可重建边界或可完成分子检测。正式申请应先覆盖全部 A 层候选，经过病例—内镜—病灶—标本—蜡块链接和组织盘点后再进入技术试点。

### 2. 纳入条件

1. 散发性传统腺瘤路径病变；
2. 病理复核确认存在 HGD，主队列优先非浸润性腺瘤内 HGD；
3. 同一蜡块或可可靠配准的连续蜡块中存在连续形态学 LGD；
4. HGD/LGD 边界可可靠描画；
5. LGD 区具有足够的近—远距离跨度；
6. 标本、蜡块、切片和内镜病灶能够建立可审计链接；
7. FFPE 余量能够满足数字切片、DNA、RNA 和至少一套空间蛋白读出；
8. 有可用匹配正常 DNA，或可获得经伦理批准的可靠胚系对照；
9. 拟进入 E1 的 near-L 能够设置 HGD exclusion buffer，并可用双人病理复核和 sandwich H&E 确认分子取材层仍为纯 LGD。

### 3. 排除或单列

- FAP、Lynch 或其他明确遗传性息肉综合征；
- 炎症性肠病相关异型增生；
- 明确锯齿通路病变；
- 严重碎片化、烧灼、方向不可还原；
- 边界无法可靠描画或无法形成连续距离；
- 特殊处理导致核酸或抗原质量明显不可用；
- 明确浸润癌不与主队列混合，可单列作延伸研究；
- 黏膜内癌和浅表浸润争议病例按冻结术语单列。

### 4. 每名患者的理想空间组合

| 代码 | 区域 | 作用 |
|---|---|---|
| W-H | 含 HGD 的赢家病灶内 HGD 区 | 克隆和病理级别参照 |
| W-L-near | 同病灶、最靠近 HGD 边界的 LGD | 边界近端状态 |
| W-L-mid | 同病灶、中间距离 LGD | 连续梯度 |
| W-L-far | 同病灶、远离边界 LGD | 病灶内远端状态 |
| B-L | 同次内镜另一枚独立、形态匹配 LGD | 同宿主旁观者病灶对照；非主队列硬性条件 |
| N | 可选正常黏膜 | 场效应与基线敏感性分析 |

正式统计使用到最近可信 HGD 边界的连续黏膜路径距离。near/mid/far 主要用于取材和展示，不替代连续距离。

## 三、分阶段样本设计

### 阶段 A：病例与组织资源审计

- 对象：现有 A 层约 110 名候选患者。
- 目的：得到真实的患者—病灶—标本—蜡块漏斗。
- 不做分子检测，不按任何表达或 P 值选择病例。
- 交付：可重建边界数、可形成距离层数、B-L 数、匹配正常数、蜡块余量和首个排除原因。

### 阶段 B：8–10 例技术开发

- 只回答能否稳定定位、取材和检测，不根据生物学方向决定是否扩展。
- 最初 5 例在 W-H、W-L-near/mid/far 等关键区各取 8–12 个腺体，建立克隆采样饱和曲线。
- 其余技术病例根据饱和结果调整腺体数。
- 比较 DNA 提取、UMI 捕获、低深度 CNA、RT-qPCR/靶向 RNA 与 mIF 的 FFPE 成功率。

技术 Go 建议同时满足：

- 至少 80% 预定区域完成回收和坐标配准；
- 至少 80% 区域 DNA 建库成功；
- 至少 70% 病例获得高置信或可回测克隆锚点；
- 至少 75% 预定 RNA 区域通过 QC；
- DNA 与 RNA/蛋白跨切片坐标可靠配对率至少 70%；
- mIF/数字病理关键读出 ICC 至少 0.75；
- 病理分级一致性 kappa 至少 0.70，距离一致性 ICC 至少 0.80；
- 至少 70% 克隆可判读技术病例具有可估计 E1 的同克隆 W-L 距离跨度：至少 2 个独立位置（优先 >=3），跨度超过仅由 L2 测量误差/腺体尺度冻结的 `D_min`；
- near-L 的双人病理复核、HGD exclusion buffer 和 sandwich H&E 反污染流程可稳定执行。

### 阶段 C：15–20 例独立生物学先导

- 不与技术开发病例混为正式确认队列。
- 只检测公共数据和技术 QC 已冻结的机制轴。
- 用于选择局部边界效应、克隆扩张、赢家病灶状态或停止旗舰四条路径之一。
- 进入正式队列的建议条件：方向约 65% 患者一致；留一患者分析稳定；效应不被病理重分级、细胞组成、组织损伤、HGD admixture 或单批次解释。L4 观察效应不直接作为正式 power 的目标效应；`Delta_target` 必须在 L4 揭盲前由公共数据、技术误差和科学最小相关效应冻结，L4 主要贡献方差/ICC/失败率。

### 阶段 D：40–60 例正式确认

- 目标为 40–60 名最终 E1 可分析患者，不是初始候选数。
- L1 先计算 `N_formal_untouched = N_resource_eligible - N_TECH - N_PILOT`；若 <40，单中心正式确认在数学上不可能完成，必须提前多中心。
- L3 再以病例级 E1 可分析比例的一侧 80% Wilson 下限形成保守 `p_E1_plan`，计算 `N_E1_expected = N_formal_untouched × p_E1_plan`；只有 `N_E1_expected >=40` 才可批准单中心正式确认。
- 如超过 30% 候选病例无法形成可靠连续距离，停止“梯度”主张，转为克隆锚定的病灶状态研究。

## 四、需要申请的数据

完整字段级清单见 `01_25F数据与材料申请表_20260826.tsv`。对外申请建议分四张单，避免数据权限和组织调取混在一起。

### 申请单 A：病理与标本库

必须申请：

- 匿名患者、病理报告、标本、蜡块和切片的稳定关联键；
- 组织学家族、最高级别、HGD 局灶性、浸润状态、切缘和碎片化程度；
- 蜡块年份、特殊处理、剩余组织等级、已有 HE/特殊染色/IHC 清单；
- 每块是否含连续 HGD/LGD、是否可形成 near/mid/far 距离层；
- 匹配正常组织或其他可用胚系对照；
- 玻片和蜡块可调取状态、预计可切层数；
- 同一标本全部蜡块，而非只申请诊断代表块。

病理复核工作：

- 胃肠病理医师复核 HGD/LGD 和传统腺瘤路径；
- 描画 HGD/LGD 边界和不确定置信带；所有拟进入 E1 的 near-L 边界区需第二名胃肠病理医师独立复核；
- 标注糜烂/修复边界、非 HGD 形态边界和与真边界在病灶拓扑、边缘距离、可用黏膜长度上匹配的伪边界作为阴性对照；
- 冻结 W-H、W-L-near/mid/far、B-L 和 N 的坐标；
- 至少 20% 病例做完整重复标注以评估总体一致性；near-L 双人复核不受该 20% 抽样限制。

### 申请单 B：内镜与病灶链接

必须申请：

- 内镜日期、指征、肠道准备、检查完整性；
- 同次检查病灶总数；
- 每枚病灶的部位、大小、巴黎分型/形态、切除方式、整块切除和完整性判断；
- 病灶—标本—病理号的对应描述；
- 同次内镜独立 LGD 病灶，用于建立 B-L 亚队列；
- 7/14/30/60/90 天候选链接窗口，以便审计错链和漏链。

### 申请单 C：最小 HIS/遗传排除信息

仅申请完成纳排和必要敏感性分析的最小字段：

- 性别、伦理允许的年龄带；
- FAP/Lynch/其他遗传性息肉综合征标志；
- 炎症性肠病标志；
- 既往结直肠肿瘤史；
- 如伦理允许，家族史和遗传检测是否存在，不必在分析区保留原始报告或直接身份信息。

本旗舰不需要大范围住院诊疗、用药或全量 LIS 数据。若后续形成独立临床论文，再另行申请，不要让 HIS 难度阻塞病理旗舰。

### 申请单 D：组织与检测材料

按优先顺序申请：

1. HE 全切片扫描及坐标；
2. 连续未染切片或可供显微切割的膜片；
3. W-H、W-L-near/mid/far、B-L 的上皮富集或腺体级取材；
4. 匹配正常 DNA；
5. DNA 克隆发现和患者特异事件回测；
6. 预注册靶向 RNA/RT-qPCR；
7. mIF/IHC 空间验证。

组织不足时不得为了做更多 IHC 而牺牲边界坐标和克隆锚定。

## 五、拟申请的病理与分子检测

### 1. 数字病理

- HE 全切片扫描、连续切片配准和层号记录；
- 沿黏膜/腺体连续结构计算到最近 HGD 边界的路径距离；
- 禁止跨皱襞、裂隙、组织折叠取几何捷径；
- 保存距离值、边界不确定度、路径版本、坐标和人工修订日志；明确距离是参考切面内的 2D 黏膜路径距离，不解释为真实 3D 生物距离；
- 量化上皮比例、间质比例、坏死/糜烂、炎症、切片质量和可判读腺体分母。

### 2. 克隆锚定

发现阶段：

- W-H、W-L-far 和 B-L 的较大上皮富集区；
- 匹配正常 DNA；
- 100–300 基因 UMI 靶向测序；
- 低深度 WGS/CNA 或等效 CNA 方法；
- 样本指纹 SNP、污染和交叉样本检查。

腺体验证阶段：

- 对全部距离带回测患者特异私有 SNV/indel、特异断点、信息性 CNA/线粒体事件；
- 优先 UMI 靶向复测或数字 PCR；
- 保存参考/变异 UMI 数、VAF、位点检出限和 QC；
- 克隆判定须盲于空间表型；高置信关系原则上需要至少两类相互支持证据；可能由 HGD 细胞低比例混入造成的成组低 VAF HGD-private 事件不得单独提升克隆支持等级。

### 3. RT-qPCR/靶向 RNA

RT-qPCR 是预注册机制轴的支持性读出，不承担克隆定义，也不得在正式队列中重新筛基因。

开发面板建议控制在 12–16 个目标基因和 3 个候选内参以内，最终根据公共数据稳健性、FFPE 可测性和技术重复性冻结。当前优先开发：

- TGFβ 信号：`TGFB1`、`TGFBR2`、`SMAD7`、`SERPINE1`；
- ECM/成纤维状态：`COL1A1`、`COL3A1`、`FN1`、`FAP`、`ACTA2`、`CCN2`；
- 条件性上皮损伤/再生：从公共数据冻结 2–3 个成员；
- 候选内参：`RPLP0`、`PPIA`、`TBP`，根据 FFPE 稳定性选择，不预设使用 ACTB/GAPDH。

要求：

- 尽量使用显微切割的区室或腺体，不使用未校正细胞组成的整块 qPCR 作为主要证据；
- 记录 DV200/可替代 RNA 质量指标、输入量、Ct、技术重复和失败原因；
- 主复合终点的成员和方向由公共数据与技术 QC 冻结，不能根据距边界的 P 值选择。

### 4. IHC/mIF

优先开发两套小面板：

1. 上皮—间质面板：pan-CK/上皮标记、pSMAD2/3、FAP 或 alpha-SMA、Ki-67、核标记；
2. 免疫可见性面板：pan-CK、HLA-I 或 B2M、CD8、CD103、GZMB、核标记。

最终旗舰只冻结一个区室明确、重复性最佳的主要表型。抗体选择按 FFPE 染色质量、区室可解释性和重复性决定，不按距离效应或 P 值决定。普通整片 H-score 不能替代上皮、基质和免疫区室的空间定量。

## 六、申请的分析任务

完整任务级清单见 `02_25F分析任务申请表_20260826.tsv`。

### 1. 数据工程与病例漏斗

- 患者去重并冻结 index episode/index lesion；
- 建立 patient—episode—lesion—specimen—block 五级关系；
- 对未使用稳定键直连的病例进行人工链接审计；
- 每名患者只保留一个首个排除原因；
- 分别报告患者、病灶、标本和蜡块分母；
- B-L 作为嵌套亚队列，不作为主队列排除条件。

### 2. 数字病理与空间分析

- 边界和区域标注一致性；
- 连续切片配准误差；
- 路径距离和不确定度；
- near/mid/far 的可重复取材规则；
- 真边界与假边界/修复边界阴性对照；
- 腺体采样饱和曲线和区域内异质性。

### 3. 克隆分析

- 体细胞事件过滤、患者特异锚点发现和检出限估计；
- 腺体级克隆支持分级：strong、moderate、uncertain、not_supported、not_evaluable；
- 每区可判读腺体数和与 W-H 同克隆腺体比例；
- 增采腺体后主克隆归属改变率；
- 常见热点和宽臂 CNA 不能单独驱动克隆判定。

### 4. 表型分析

- 只使用冻结机制轴；
- 评估成员一致性、leave-one-gene-out、技术重复性和区室来源；
- 主要平台和主要区室在先导后一次性冻结；
- IHC/mIF、RNA 和数字病理做正交一致性，不以跨平台都显著为成功条件。

### 5. 正式统计终点

主要终点 E1：

> 在与 W-H 有强或中等克隆支持的形态学 W-L 腺体中，冻结主表型随 `log2(1 + distance/mm)` 变化的患者内平均斜率。

主要估计框架：

1. 技术重复先合并，腺体先形成区域/距离位置的冻结表型；
2. 每名 E1 患者在 strong/moderate same-clone W-L 内估计 `phenotype ~ f(log2(1 + distance_mm))` 的患者级斜率；
3. 以患者等权汇总斜率并进行双侧 `alpha=0.05` 检验；
4. 层级混合模型、患者聚类稳健标准误和空间相关模型作为支持性一致性分析。

E1 不放入 `distance×clone_support`；该交互只在 E4 的全部克隆可判读 W-L 中估计。

关键次要终点：

- E2：W-H 与 W-L-near 的边界跃迁；
- E3：W-L-far 与同患者 B-L 的配对差；
- E4：连续距离与 clone_support 的交互；
- E5：同区腺体一致率、ICC 和克隆不一致率。

预指定敏感性因素：病理重分级、上皮/间质比例、标本年代、固定和烧灼、切除方式、批次、距离不确定度、克隆不确定病例、是否存在 B-L。

## 七、结果解释与转向规则

| 观察结果 | 研究结论与下一步 |
|---|---|
| 同克隆 W-L 内仍有距离梯度，W-L-far 接近 B-L | 推进“局部 HGD 边界场”旗舰 |
| 克隆关系显著，校正后距离梯度消失 | 转为“克隆扩张与高级化状态” |
| W-L-far 仍不同于 B-L，但 W-L 内无梯度 | 转为“赢家病灶固有状态” |
| 仅 W-H 与 LGD 不同 | 只是普通病理分级差异，停止旗舰 |
| 只有单基因或单平台显著 | 不升级；保留探索性结果 |
| 所有预注册轴不稳定 | 停止分子旗舰；仅在克隆图谱足够新时形成资源/方法论文 |

## 八、当前最先需要病理科确认的事项

1. A 层候选患者的全部标本和蜡块能否批量盘点；
2. 可重建 HGD/LGD 连续边界的真实病例数；
3. 每例可用的连续切片层数和组织余量；
4. 是否能提供同患者匹配正常组织；

## 九、对外申请摘要文本

> 本研究拟在散发性结直肠传统腺瘤 HGD 病例中，利用既往 FFPE 标本和数字病理重建 HGD/LGD 真实边界，判断同一患者、同一形态学等级的 LGD 在靠近 HGD 时是否存在可重复的分子/空间状态，并区分局部边界关联、克隆扩张和整枚病灶状态。第一阶段仅对现有约 110 名候选患者进行病灶—标本—蜡块链接和组织资源盘点，不批量新切片；第二阶段选择 8–10 例开展边界配准、HGD exclusion buffer、near-L 双人病理复核、sandwich H&E、腺体级克隆锚定及冻结表型的技术验证。技术达标后再以独立 15–20 例评估方向、方差和失败率，正式确认要求最终获得 40–60 名同克隆距离跨度可识别且反污染 QC 通过的 E1 可分析患者。研究只使用既往诊疗资料与剩余组织，不因本研究增加患者检查；诊断安全余量由病理负责人优先锁定。患者为唯一独立统计单位，公共数据仅用于候选机制和外部参照，不能替代本院真实边界验证。
