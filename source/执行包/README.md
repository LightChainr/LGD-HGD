# 25F 病理分子申请与分析执行包（修订版）

本包用于把 25F 从候选病例盘点逐层推进到正式确认性研究。执行原则是“先分母、再几何、后分子；先技术、后生物学；每层通过闸门才扩大”。

本修订版额外冻结四个保护性规则：**正式队列资源闭合、E1 同克隆距离可识别性、HGD→near-L 病理/切片污染防护、患者等权主估计量**。这些规则优先于旧版中任何较宽松表述。

## 文件顺序

1. `00_25F具体执行方案与申请说明_20260826.md`：研究问题、总体设计和对外申请摘要；
2. `01_25F数据与材料申请表_20260826.tsv`：数据、组织和检测材料申请清单；
3. `02_25F分析任务申请表_20260826.tsv`：分析任务、负责人、输出和闸门；
4. `03_25F分层实施与闸门SOP_20260826.md`：逐层启动、暂停、降级和锁库规则；
5. `04_25F病理科执行清单_20260826.tsv`：病理科逐例操作清单；
6. `05_25F组织分配与切片预算模板_20260826.tsv`：每例组织分配、保留和实际消耗记录模板；
7. `06_25F最小数据申请分层表_20260826.tsv`：按 M0–M3 分层申请，避免一次性申请过宽；
8. `07_25F统计分析冻结摘要_20260826.md`：主要估计量、分析集、协变量和敏感性分析冻结框架；
9. `08_25F部门交接与RACI_20260826.tsv`：病理、内镜、数据、分子、生信、统计的责任边界；
10. `09_25F启动会议确认单_20260826.md`：启动会议逐项确认和签署模板；
11. `10_依据与冻结合同/`：v1.8 后续分析计划、完整数据字典、终点和分析目标合同；
12. `11_25F临床沟通与启动会话术_20260826.md`：与消化内科、病理科主任的临床化沟通框架；
13. `12_25F修订说明_20260826.md`：本轮关键风险修订及新硬闸门。

## 建议立即执行

只启动 L0–L2：

- L0：冻结约 110 名 A 层候选患者及 index 病灶链接；
- L1：盘点全部相关蜡块、HE、正常对照和同步 B-L；
- L2：从资源合格病例中选 8–10 例验证边界、配准、距离及 HGD 污染防护流程；病例覆盖不同块龄和取材方式，不只挑“最好材料”。

在 L2 通过前不批量切取正式队列，不启动 40–60 例分子检测；在 L3 形成保守的病例级 E1 可分析率并证明剩余未使用病例预计可产生至少 40 名 E1 可分析患者前，也不得批准单中心正式确认队列。
